# 🌾 AgroSustentável — Agro Forte, Futuro Sustentável

Uma landing page moderna e responsiva dedicada a promover a sinergia entre a alta produtividade no campo e a preservação ambiental. O projeto destaca o papel da tecnologia de precisão, manejo inteligente de recursos e uso de energias limpas no agronegócio moderno.

---

## 🚀 Demonstração Visível
O projeto consiste em uma página única (*Landing Page*) com navegação suave, design focado na experiência do usuário (UX) e uma paleta de cores totalmente inspirada na natureza e na sustentabilidade.

---

## 🧠 Pilares do Projeto

* **🌱 Produção Eficiente:** Destaque para o uso de tecnologias de precisão que otimizam o espaço e reduzem o impacto no solo.
* **💧 Manejo de Recursos:** Sistemas inteligentes voltados para a irrigação eficiente e captação da água da chuva.
* **🔄 Energia Limpa:** Transição para matrizes 100% renováveis, como a solar e a biomassa.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais, sem a necessidade de frameworks complexos, garantindo leveza e carregamento rápido:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização personalizada utilizando **Variáveis CSS** (*Custom Properties*) para fácil manutenção de cores, além de layouts modernos e responsivos.
* **JavaScript (Vanilla):** Manipulação dinâmica do DOM (como o ajuste dinâmico do tamanho do cabeçalho principal).
